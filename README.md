# Sistema de Delivery - Fila de Entregas

Um sistema em Python desenvolvido para gerenciar o fluxo de logística e despacho de pedidos em um estabelecimento de delivery. O projeto simula a rotina real de gerenciamento de ordens de entrega e organização da fila de motoboys.

## Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de consolidar os conceitos estruturais de dados tipo Fila (FIFO - First In, First Out). Ele organiza os pedidos que entram no sistema e os atribui aos motoboys disponíveis na ordem exata de chegada , garantindo um fluxo de entregas justo e eficiente.

## Tecnologias Utilizadas 

* **Python:** Linguagem principal utilizada para construir toda a lógica de negócios, controle das listas e condicionais.

## Funcionalidades Principais (Esqueleto)

- [x] Registro e inserção de novos pedidos na fila de entrega.
- [x] Sistema automatizado de despacho com remoção ordenada de pedidos e motoboys.
- [x] Proteção e tratamento de erros para filas vazias (impedindo falhas no sistema).
- [x] Visualização em tempo real do status da fila e dos entregadores disponíveis.

 ## Como executar o Projeto

Para rodar este projeto na sua máquina local, você precisará ter o Python instalado.

1. Clone este repositório para a sua máquina:
   ```bash
   git clone [https://github.com]
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd sistema-delivery-motoboy
   ```

3. Execute o script principal utilizando o comando:
   ```bash
   python Sistema_delivery.py
   ```
